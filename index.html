Como atualizar

Envie o arquivo Excel com as abas Base de Dados - Separacao e Base de Dados - Conferencia. Cada importação substitui integralmente os registros das datas presentes no arquivo, sem duplicar o acumulado. Os demais dias já importados permanecem salvos no banco compartilhado. A produção por hora usa a hora de confirmação da separação e a hora de fim da conferência.

A contagem de caixas considera cada número de caixa uma única vez por usuário e hora. Caixas com múltiplos itens não são contadas várias vezes.

PRODUTIVIDADE SPI-PP — ATUALIZAÇÃO

Substituir no repositório GitHub os arquivos index.html, server.py e requirements.txt.
Manter no Render as variáveis DATABASE_URL, UPLOAD_KEY e VIEW_KEY.
O usuário admin entra com a senha definida em UPLOAD_KEY.
O usuário visualizador entra com a senha definida em VIEW_KEY.
Não colocar senhas no GitHub. Para segurança adicional, configure SESSION_SECRET no Render com uma senha longa e aleatória.
O painel atualiza automaticamente a cada 30 segundos para usuários conectados.

Logotipos: colocar arquivos oficiais em logos/gruposc.png e logos/panpharma.png no repositório. Enquanto não forem fornecidos, os espaços de imagem ficam ocultos e os nomes permanecem visíveis.

Importante: dados existentes no Neon são preservados. O novo login usa sessão segura no servidor; não depende das chaves digitadas no navegador.
